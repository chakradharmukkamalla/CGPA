# 🎓 VIT CGPA Calculator

A fast, simple, and responsive **CGPA Calculator built specifically for VIT students**.

After weeks of building, testing, and refining, this project aims to make CGPA calculation and academic planning easier — especially for students dealing with **grade improvements, arrears, and projected grades**.

🔗 **Live Demo:** https://vitcgpa-eta.vercel.app/

---

## ✨ Features

### 💡 Grade Improvement & Arrears Support

Academic histories aren't always straightforward.

This calculator is designed to handle scenarios involving:

- Grade improvements
- Arrears
- Previous and current grades
- Different course credit weights
- CGPA prediction and what-if scenarios

Get a more realistic estimate of how your academic decisions could affect your CGPA.

### 📱 Fully Responsive

Built with a mobile-first approach so you can use it comfortably on:

- 📱 Mobile
- 💻 Laptop
- 🖥️ Desktop
- 📟 Tablet

### ⚡ Fast & Lightweight

Built using **React + Vite** for a fast and modern development experience.

No unnecessary complexity — just a focused tool that gets the job done.

### 🎯 Simple & Student-Friendly

> Enter your academic information → Calculate your CGPA → Make better academic decisions.
